IT Kamianets AI Framework

Створюйте AI-агентів з багаторазових пакетів

Поєднуйте рушій агентів на Node.js, локальні моделі Ollama та інструменти для Unity, Assetra або Firebase.

Переглянути пакети

Пакети заплановані. Назви та API можуть змінитися.

Один рушій, будь-яка область

ai-core нічого не знає про Unity чи Firebase. Моделі та інструменти підключаються як пакети.

  1. ai-coreвиконує цикл агента, інструменти та сесії
  2. ai-ollamaзапускає локальну модель
  3. ai-unityдає агенту руки в Unity Editor
Читати документацію 
import { createAgent } from '@itkamianets/ai-core';
import { ollama } from '@itkamianets/ai-ollama';
import { unityTools } from '@itkamianets/ai-unity';

const agent = createAgent({
  name: 'my-agent',
  provider: ollama({ model: 'auto' }),
  tools: [...unityTools()],
  rules: ['./rules'],
  skills: ['./skills'],
});

await agent.chat();

Три шари, один напрямок

Кожен шар спирається на попередній.

  1. ai-*

    Пакети фреймворку

    Рушій, провайдери моделей та інтеграції інструментів.

  2. ai-constructor-*

    Конструктори

    Стартовий репозиторій для одного типу агента.

  3. <agent>-*

    Ваш агент

    Промпти, правила, навички та команда залишаються поза фреймворком.

Пакети

Усі пакети
  • ai-api-schemaКонтракт між агентом і його застосунками: HTTP-ендпоінти, потокові події, сесії та виклики інструментів як JSON Schema.
  • ai-coreРушій агента: провайдери моделей, інструменти, промпти, правила, навички, сесії, дозволи та HTTP API з потоковою передачею.
  • ai-ollamaЛокальні моделі через Ollama: знайти, встановити, налаштувати, порадити, завантажити, оновити, видалити і запустити моделі.
  • ai-unityІнструменти Unity Editor: огляд сцен, створення, переміщення, обертання, масштабування й видалення об'єктів і налаштування матеріалів.
  • ai-assetraІнструменти Assetra: пошук, завантаження, публікація й керування 3D-моделями у спільній бібліотеці.
  • ai-firebaseІнструменти Firebase: Authentication, Firestore, Realtime Database і Cloud Storage для агента.

Агенти та конструктори

Усі агенти
  • openUnityAI-агент для Unity Editor
  • CLI-агентКонструктор: Команда в терміналі
  • Застосунок агентаКонструктор: Вебзастосунок, мобільний і десктопний застосунок для агента
